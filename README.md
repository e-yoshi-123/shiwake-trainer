# 会計仕訳クイズトレーナー

簿記3級レベルの「仕訳 ⇔ 業務パターン」の反射的な変換能力を鍛えるためのクイズ形式学習アプリです。
単一のHTMLファイル（`index.html`）で完結しており、サーバー不要・ブラウザだけで動作します。

## 使い方

`index.html` をブラウザで開くだけで利用できます。ダブルクリックでローカルファイルとして開いても動作します。

## 出題形式

- **形式A**: 仕訳 → 業務パターン当てクイズ
- **形式B**: 業務パターン → 仕訳穴埋めクイズ
- **形式C**: ホームポジション・BS/PL判定クイズ
- **形式D**: 正常系 → 異常系 応用クイズ
- **ミックスモード**: 形式A・Bをランダムに混ぜて出題

詳細な仕様は `会計仕訳クイズ_指示書.md` を参照してください。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク不使用）
- グラフ表示に [Chart.js](https://www.chartjs.org/)（CDN経由）を使用
- 状態はセッション内のJS変数のみで管理（localStorage等は不使用）
